Best-effort: report a Tendril breakage so the owning project can turn it into a bead / logged error.

This never fails or blocks the CLI’s own error path — feedback delivery errors are swallowed, because the breakage is already surfaced to the user via emit_error. When feedback is unconfigured the reporter is disabled and this is a no-op.
