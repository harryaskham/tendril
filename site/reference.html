Configuration

Machine-local defaults live in ~/.config/tendril/config.yaml, or $TENDRIL_CONFIG_DIR/config.yaml. Flags override it.

capture:  format: png            # or jpeg  compression: 85        # 0–100  max_width: 512         # captures fit a 512 × 512 box unless raised  max_height: 512  timeout_ms: nulllogging:  level: info            # error, warn, info, debug or traceexecution_lock:  enabled: true  timeout_ms: 60000      # how long a run waits in the queue  stale_ms: 30000        # heartbeat age before a holder is reaped  path: null             # default: under the temporary directoryfeedback:                # optional; off when omitted  enabled: true  component: tendril  strategy:    type: webhook        # webhook, caco_cli, file, stderr or disabled    url: https://example.invalid/feedback    token_env: TENDRIL_FEEDBACK_TOKEN

Updates

tendril update uses the shared release flow: it discovers a newer tagged release, verifies its checksum, stages it and promotes it at the next start. tendril version prints the running version without touching anything.

Rust API

The workspace's Rust documentation is generated at publish time and served under api/: the tendril library and binary, the Windows backend crate and the shared command surface.
